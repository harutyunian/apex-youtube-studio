# Apex YouTube Studio (Русская документация)

> **Универсальная AI-студия полного цикла для создания и жёсткого контроля качества YouTube-видео и обложек.**  
> **9 специализированных субагентов** (Продюсер, Сценарист, Режиссёр/Оператор, Монтажёр/Звукорежиссёр, Критик обложек, Судья удержания, Визуальный Супервизор-судья, Панель из 10–24 зрителей, Финальный арбитр релиза) + **25 скиллов** + **Python-скрипты проверки ДО и ПОСЛЕ**.

Работает для **любой ниши** (финансы, документалки, технологии, история, тру-крайм, образование, сторителлинг, Shorts, говорящая голова или AI-видео) и ставится в **OpenCode** или **Claude Code** одной командой.

---

## Главная идея: контроль «ДО и ПОСЛЕ» на каждом этапе

Система физически не даёт тратить часы на рендер слабого ролика или кривой обложки:

1. **Этап 1 — ДО генерации обложки (`PRE_GENERATION`):**
   - `youtube-producer` подбирает 10 заголовков (`title.py`) и пишет бриф (`yt-thumbnail-brief`).
   - `audit_thumbnail.py --brief` и судья **`thumbnail-auditor`** проверяют: план под **TV 50%** (верхняя половина экрана TV), психологию **Questions + Emotions** без заголовка, механизм из 5 источников референсов, очистку мусора, выделение героя и **3+ A/B варианта текста** с `0%` пересечения слов с Title.
2. **Этап 2 — ПОСЛЕ генерации обложки (`POST_GENERATION`):**
   - `audit_thumbnail.py --thumb` рендерит 4-панельный лист `_thumbnail_diagnostic_sheet.jpg` (`Полный 16:9` | `TV 50% маска` | `120px телефон` | `Без заголовка`).
   - **`thumbnail-auditor`** глазами проверяет все 8 гейтов (`luma_std >= 42.0`, читаемость в верхней половине TV, сходство лица с эталоном, отсутствие мусора).
3. **Этап 3 — ДО генерации озвучки, AI-клипов и рендера видео (`PRE_RENDER`):**
   - `youtube-screenwriter` и `youtube-director-dp` собирают сценарий, раскадровку/EDL и промпты сцен.
   - `hookscore.py --title` + `audit_retention_architecture.py --transcript --edl` + судья **`retention-auditor`** (`PRE_RENDER`) проверяют до рендера:
     - `0–5s`: 1-я фраза совпадает с Title, 1-й кадр с обложкой, голос сразу поясняет смысл превью;
     - `0–20s`: Контекст + Ставки/Награда + Интрига + **Input Bias** (видны реальные усилия/источники с 0-й секунды) + **`>= 8` смен кадров в 20 сек** + старт тела видео **`<= 0:20`**;
     - Тело видео: нет статичных кусков `>= 10s`, нет скучных склеек внутри «одной комнаты/шаблона», нет случайных несвязанных прыжков (`New York -> Chicago`), включая **AI-видео**; есть непрерывный контраст и **2–4 минутные циклы энергии** (быстрые в начале, тяжёлые эмоции в последних `20%`); финал на высокой ноте.
4. **Этап 4 — ПОСЛЕ рендера MP4 (`POST_RENDER`):**
   - `youtube-editor-sound` проверяет отсутствие тишины (`deadair.py`), нормализацию `-14.5..-16.0 LUFS`, главы (`chapters.py`) и сборку.
   - **`visual-supervisor-judge`** прогоняет `inspect_chapter.py` (`PySceneDetect`, `START|MID|END` контакт-листы) и независимый мультимодальный аудит видео целиком по 15 критериям (`CRITICAL == 0`).
   - **`retention-auditor`** (`POST_RENDER`) проверяет 13 гейтов на реальном MP4 и проводит **«10-blunt-friends roast»** (где зрителю стало скучно, непонятно или тяжело следить).
   - **`viewer-panel-critic`** прогоняет видео через панель из **10–24 разных зрителей** (человек в метро с телефоном, эксперт, зритель на TV, скептик AI и т.д.).
   - **`santa-release-judge`** запускает двух независимых ревьюеров для финального `PASS / PASS` перед публикацией.

## Быстрая установка

```bash
git clone https://github.com/harutyunian/apex-youtube-studio.git
cd apex-youtube-studio
pip install -r requirements.txt
cp .env.example .env  # вписать GEMINI_API_KEY

# Установить агентов и скиллы в OpenCode и Claude Code:
./install.sh --all

# ИЛИ развернуть шаблон нового YouTube-проекта:
./install.sh --project /path/to/my-youtube-channel
```

Смотри подробности по каждому агенту в [`docs/AGENTS_ROSTER.md`](AGENTS_ROSTER.md) и пошаговые команды в [`docs/WORKFLOW.md`](WORKFLOW.md).
