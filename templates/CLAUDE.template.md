# Studio Production Constitution (`CLAUDE.md`)

> Universal production standard powered by **Apex YouTube Studio**.

## 1. Channel & Format Baseline
- Load `CHANNEL_PROFILE.md` at the start of every episode.
- **Audio Target:** `-14.5 to -16.0 LUFS` integrated loudness, `<= -1.0 dBTP` true peak, zero dead-air gaps `> 0.35s` in narration (`> 0.55s` in master).
- **Resolution:** `1920x1080` (or `3840x2160`) @ `30fps`, crisp typography, `0` accidental black frames.

## 2. Full Crew Responsibilities
1. **Producer (`youtube-producer`):** Outlier research (`swipe.py`), 10x Escalation Arc, `title.py` (`>= 90` score), `yt-thumbnail-brief` (`KE4zqD0ONDI` rules).
2. **Screenwriter (`youtube-screenwriter`):** `0:00–0:05` Title/Thumbnail Lock -> `0:00–0:20` Context + Stakes + Curiosity Gap + Input Bias -> Body start `<= 0:20` -> `2–4 min` High->Low energy cycles (faster upfront, heavy emotional weight in final `20%`) -> Big Payoff + High-Note End (no farewell cliff).
3. **Director & DP (`youtube-director-dp`):** Multi-world visual palette, `2.0–3.5s` context-driven shot progression (`Wide -> Medium -> Close-Up -> Angle`), Continuous Contrast, zero same-room cuts, zero unmotivated random location jumps (`NY -> Chicago`, including AI-generated video), honest provenance (`DRAMATIC RECONSTRUCTION`).
4. **Editor & Sound (`youtube-editor-sound`):** Frame-accurate HyperFrames/FFmpeg assembly, `deadair.py` cuts, sidechain BGM pocket, tactile SFX punctuation, verified YouTube chapters (`chapters.py`).
5. **Critics, Viewers & Judges (`thumbnail-auditor`, `retention-auditor`, `visual-supervisor-judge`, `viewer-panel-critic`, `santa-release-judge`):** Enforce BOTH `BEFORE` (`PRE_GENERATION` / `PRE_RENDER`) and `AFTER` (`POST_GENERATION` / `POST_RENDER`) gates until `PASS`.
